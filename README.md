# MacPulse – Mac Productivity Dashboard

A lightweight, modern, macOS-inspired productivity dashboard built with HTML, CSS, and vanilla JavaScript.

MacPulse provides a simple workspace for managing daily tasks, tracking focus sessions, and organizing productive work.

## Features

- **Live Clock & Date:** Displays the current time and date.
- **Task Manager:** Add, complete, delete, and filter tasks.
- **Pomodoro Timer:** Manage focused work sessions and breaks.
- **Dark & Light Mode:** Switch between two visual themes.
- **Local Storage:** Automatically saves tasks, theme preferences, and completed focus sessions.
- **Responsive Design:** Works across desktop, tablet, and mobile screens.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Browser Local Storage
- Visual Studio Code

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Navigate into the project

```bash
cd MacPulse
```

### 3. Open the application

Open `index.html` directly in your browser, or use the VS Code Live Server extension.

## How to Use

1. Open the dashboard in your browser.
2. Add tasks using the task input field.
3. Mark tasks as completed or delete them.
4. Use the Pomodoro timer to manage focused work sessions.
5. Switch between focus and break modes.
6. Toggle dark and light themes.
7. Refresh the browser to verify that saved preferences and tasks remain available.

## Project Objective

The objective of MacPulse is to demonstrate practical frontend development skills, including DOM manipulation, event handling, JavaScript timers, browser storage, and responsive user interface design.
